# Asie, été 2027

App de voyage hors ligne (PWA) : planning jour par jour, réservations et billets synchronisés entre deux iPhone via Firebase.

- Le site publié est à la racine (fichiers construits).
- Le code source est dans `source/` (`npm install` puis `node build.mjs`, sortie dans `dist/`).
- Les règles de sécurité Firestore sont dans `firestore.rules`.
